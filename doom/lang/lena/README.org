#+title:    :lang lena
#+subtitle: Lean 4 with Lena and its infoview
#+created:  October 05, 2026

* Description
This Doom Emacs module sets up [[https://github.com/ISTA-PLV/nael][Lena]], ISTA PLV's fork of Nael and a major mode
for Lean 4, including its infoview: a window that shows the goals and the
expected type at point, whose subterms can be described and followed to their
definitions.

It replaces Doom's own =:lang lean= module, which uses upstream Nael; do not
enable both.

** Module flags
- +lsp :: Start the Lean server in Lean buffers, with Eglot. Lena uses Eglot
  only, also if Doom's =:tools lsp= module uses lsp-mode for other languages.

* Installation
Doom finds private modules in =~/.doom.d/modules/=. Link this module there:

#+begin_src sh
mkdir -p ~/.doom.d/modules/lang
ln -s /path/to/lena/doom/lang/lena ~/.doom.d/modules/lang/lena
#+end_src

In =~/.doom.d/init.el=, replace =(lean +lsp)= with =(lena +lsp)= under =:lang=, then run =doom sync=.

To work on Lena itself, declare it in =~/.doom.d/packages.el= with your checkout, which takes precedence over this module's declaration:

#+begin_src emacs-lisp
(package! lena :recipe (:local-repo "/path/to/lena"
                        :files ("lena/*.el" "lena/lena.info" "lena/lena.texi"
                                "lena/NOTICE" "lena/LICENSE*")))
;; With Evil:
(package! lena-evil :recipe (:local-repo "/path/to/lena"
                             :files ("lena-evil/*.el" "lena-evil/LICENSE")))
#+end_src

* Usage
In Lean buffers, under =SPC m=:

| Key       | Command                     |
|-----------+-----------------------------|
| =SPC m i= | toggle the infoview         |
| =SPC m r= | reprocess the file, building its imports |
| =SPC m a= | abbreviations for the character at point |
| =SPC m b= | build the project           |
| =SPC m e= | ElDoc's documentation buffer |

In the infoview, under =SPC m=: =r= refresh, =v= view options, =y= copy the goal at
point. In normal state, =]g= and =[g= go to the next and previous goal, =]h= and =[h= to
headings, =gr= refreshes, and on a subterm =K= or =RET= describes it, =gd= goes to its
definition and =C-o= comes back. The descriptions open in =*Lena Help*=, where =C-o=
and =C-i= go back and forth and =q= closes.
