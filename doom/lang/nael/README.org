#+title:    :lang nael
#+subtitle: Lean 4 with Nael and its infoview
#+created:  October 05, 2026

* Description
This Doom Emacs module sets up [[https://github.com/ISTA-PLV/nael][Nael]] (ISTA PLV's fork), a major mode for Lean 4, including its infoview: a window that shows the goals and the expected type at point, whose subterms can be described and followed to their definitions.

It replaces Doom's own =:lang lean= module, which uses upstream Nael; do not enable both.

** Module flags
- +lsp :: Start a language server in Lean buffers, with Doom's =:tools lsp= module.  The infoview needs Eglot, that is =(lsp +eglot)=; with lsp-mode, Nael shows goals with ElDoc only.

* Installation
Doom finds private modules in =~/.doom.d/modules/=.  Link this module there:

#+begin_src sh
mkdir -p ~/.doom.d/modules/lang
ln -s /path/to/nael/doom/lang/nael ~/.doom.d/modules/lang/nael
#+end_src

In =~/.doom.d/init.el=, replace =(lean +lsp)= with =(nael +lsp)= under =:lang=, then run =doom sync=.

To work on Nael itself, declare it in =~/.doom.d/packages.el= with your checkout, which takes precedence over this module's declaration:

#+begin_src emacs-lisp
(package! nael :recipe (:local-repo "/path/to/nael"
                        :files ("nael/*.el" "nael/nael.info" "nael/nael.texi")))
#+end_src

* Usage
In Lean buffers, under =SPC m=:

| Key       | Command                     |
|-----------+-----------------------------|
| =SPC m i= | toggle the infoview         |
| =SPC m r= | reprocess the file, building its imports |
| =SPC m a= | abbreviations for the character at point |
| =SPC m b= | build the project           |
| =SPC m e= | ElDoc's documentation buffer |

In the infoview, under =SPC m=: =r= refresh, =v= view options, =y= copy the goal at point.  In normal state, =]g= and =[g= go to the next and previous goal, =]h= and =[h= to headings, =gr= refreshes, and on a subterm =K= or =RET= describes it, =gd= goes to its definition and =C-o= comes back.  The descriptions open in =*Nael Help*=, where =C-o= and =C-i= go back and forth and =q= closes.
